# project1_so.Galuh-sistem-manajement-file-pribadi

gambar 1 : https://drive.google.com/file/d/1FtLWokchHefHkVh4Xz0YsocPp3a7VYZf/view?usp=sharing

mkdir Myfiles
Membuat folder baru bernama Myfiles di drive C.

cd Myfiles
Masuk ke dalam folder Myfiles.

mkdir documents picture videos music
Membuat empat folder sekaligus yaitu documents, picture, videos, dan music.

echo. > laporan.txt
Membuat file kosong bernama laporan.txt.

echo. > gambar.pdf
Membuat file kosong bernama gambar.pdf.

echo. > video.mp4
Membuat file kosong bernama video.mp4.

echo. > musik.mp3
Membuat file kosong bernama musik.mp3.

move laporan.txt documents
Memindahkan file laporan.txt ke folder documents.

move gambar.pdf picture
Memindahkan file gambar.pdf ke folder picture.

move video.mp4 videos
Memindahkan file video.mp4 ke folder videos.

move musik.mp3 music
Memindahkan file musik.mp3 ke folder music.

tree
Menampilkan struktur folder saja tanpa isi file.

tree /f
Menampilkan struktur folder beserta isi file di dalamnya.
